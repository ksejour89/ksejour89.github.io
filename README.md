# Kharlventz Sejour — Portfolio

Personal portfolio site, hosted on GitHub Pages at [ksejour89.github.io](https://ksejour89.github.io).

A static, single-page site — Hero, About, Skills, Certifications & Education, Projects, Experience, and Contact — built with plain HTML/CSS/JS and no build step.

## Running locally

```
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

- `index.html` — the entire site
- `assets/css/style.css` — hand-written styles
- `assets/js/script.js` — mobile nav toggle, scroll-spy nav highlighting
- `assets/css/fontawesome-all.min.css` + `assets/webfonts/` — [Font Awesome](https://fontawesome.com) icon fonts (used under the Font Awesome Free license)
- `images/` — headshot and school logos

## Deployment

Pushing to `main` updates the live site automatically via GitHub Pages.
